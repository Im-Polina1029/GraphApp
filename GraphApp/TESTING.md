# Запуск тестов GraphApp

## Unit-тесты

Unit-тесты проверяют модуль `algorithms/coloring.py` и алгоритм раскраски вершин.

```bash
python -m pytest tests/unit -q
```

В проект добавлено 10 unit-тестов:

1. граф без рёбер;
2. путь из 4 вершин;
3. треугольник;
4. цикл из 4 вершин;
5. цикл из 5 вершин;
6. граф-звезда;
7. полный граф `K4`;
8. несвязный граф: треугольник и отдельное ребро;
9. ошибка при петле на вершине;
10. ошибка при несимметричной матрице.

## Selenium-тесты

Selenium-тесты проверяют работу веб-интерфейса.

```bash
python -m pytest tests/selenium -q
```

В проект добавлено 5 Selenium-тестов:

1. на главной странице есть вариант `Раскраска вершин`;
2. поле стартовой вершины отключается при выборе раскраски;
3. страница `/about-coloring` содержит нужные разделы;
4. треугольник раскрашивается в 3 цвета через веб-форму;
5. некорректная матрица выводит страницу ошибки.

Для Selenium-тестов нужен установленный браузер и WebDriver. По умолчанию используется Chrome. Для Firefox можно указать:

```bash
SELENIUM_BROWSER=firefox python -m pytest tests/selenium -q
```
