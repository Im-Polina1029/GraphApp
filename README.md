# Граф-Визионер

**Веб-приложение для работы с неориентированными графами**  
*Учебный проект по дисциплине «Элементы теории графов»*

---

## О проекте

Граф-Визионер — это многостраничное веб-приложение, которое позволяет решать три классические задачи теории графов:

1. **Построение остовного дерева с помощью обхода в ширину (BFS)**
2. **Построение остовного дерева с помощью обхода в глубину (DFS)**
3. **Раскраска вершин графа минимальным количеством цветов**

Приложение разработано на Python с использованием микрофреймворка **Bottle**.

---

## Команда

| Участник | Вариант | Задача |
|----------|---------|--------|
| Студент 1 | Вариант 1 | BFS — обход в ширину, построение остовного дерева |
| Студент 2 | Вариант 2 | DFS — обход в глубину, построение остовного дерева |
| Студент 3 | Вариант 3 | Раскраска вершин (жадный алгоритм, обратный поиск) |

---

## Возможности

### Общие для всех вариантов
- Ввод количества вершин (от 1 до 20)
- Ввод матрицы смежности в текстовом формате
- Проверка корректности ввода
- Вывод результатов в виде HTML-таблиц
- Сохранение результата в текстовый файл
- Логирование всех запусков

### Вариант 1 — BFS
- Построение остовного дерева с помощью очереди (FIFO)
- Вывод порядка обхода вершин

### Вариант 2 — DFS
- Построение остовного дерева с помощью стека (LIFO)
- Вывод порядка обхода вершин

### Вариант 3 — Раскраска вершин
- Раскраска жадным алгоритмом
- Вывод минимального количества цветов
- Вывод раскраски каждой вершины
